# Personal Progress OS — Product Requirements

## Vision
A personal operating system measuring the gap between intended long-term outcomes and actual daily execution across career, lifestyle and fitness.

## Primary User
One personal user first. Architecture (user_id + RLS everywhere) allows multi-user later.

## Questions the app answers daily
What am I trying to achieve? What should I do today? How much did I actually do? Is my behavior moving me toward the outcome?

## Modules
Dashboard, Daily Progress, Goals & Skills, Career/Job Pipeline, Fitness, Analytics, Settings.

## MVP (V1)
Authentication, Tasks (name, category, priority 1–10, daily target, unit, active, goal link), daily focused-hour logging, optional output/evidence, weighted scoring, dashboard (today score, career/lifestyle split, focused hours, 30-day chart), goals, basic trends (7/30-day averages, consistency).

## Later
V2 job CRM + funnel + skill roadmap + weekly/monthly review. V3 gym, measurements, photos. V4 nutrition, advanced analytics, PWA. V5 multi-user SaaS.

## Non-goals
Habit-checkbox tracker, generic to-do, calendar, employability prediction, gamification.

## UX Constraint
Daily entry under 5 minutes.
